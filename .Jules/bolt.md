## 2026-10-02 - Prevent cache stampedes in memory caching
**Learning:** In a typical Express application with an external backend API (like YTMusic), adding a basic TTL cache might not be enough under concurrent load. The application's endpoints (`/library/playlists`, `/library/songs`, `/library/artists`) were all fetching the same `getHomeSections()` simultaneously when the app loaded. This caused multiple concurrent requests to the external API, bypassing the cache before it was populated.
**Action:** When implementing basic memory caches, always store and return the `Promise` of the inflight network request instead of just caching the resolved value. This way, all concurrent initial callers await the identical Promise resolving rather than triggering a cache stampede.
