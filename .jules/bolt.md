## 2025-02-28 - Optimize ytmusic home sections caching\n**Learning:** The ytmusic.getHomeSections() method is expensive and was being repeatedly called in parallel by /library/playlists, /library/songs, and /library/artists, causing performance issues. Simply caching the result without handling inflight promises can lead to "cache stampedes" where multiple concurrent requests still execute the expensive method because the cache is not yet populated.\n**Action:** Use an `inflightPromise` pattern in addition to an in-memory variable when caching expensive backend calls to ensure multiple concurrent requests await a single API response rather than executing duplicate backend queries.
