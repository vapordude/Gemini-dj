## 2025-03-05 - Request Deduplication to Prevent Cache Stampedes
**Learning:** When multiple components render concurrently and trigger the same data fetch (like fetching library tracks from the YTMusic proxy route), independent fetch calls in the API can trigger multiple identical upstream network requests. This creates a cache stampede bottleneck before caching is even fully utilized.
**Action:** Always implement inflight request deduplication alongside TTL caches. If an operation is already pending (inflightHomeSectionsPromise), return that existing promise to all concurrent callers rather than firing a new request.
